# POS Café Maker
Thai-first giveaway kit. Preserve the documented scopes and prototype labels.
Money uses integer satang. Server decides prices and permissions. Checkout, stock and refunds must be atomic and idempotent. Never expose secrets, overwrite database volumes, or imply digital checks prove physical fit or electrical performance.
One canonical model generator produces preview and printable geometry; electronic placeholders never enter STL. Every nontrivial behavior needs a meaningful test. Run npm test and npm run build; DB tests need TEST_DATABASE_URL and a disposable database. KiCad checks are independent of web/POS builds.
