# พิมพ์เขียวต้นแบบสำหรับนำไปสร้างต่อ

ชุดนี้แจก source และแบบ CAD ที่แก้ไขได้ ผู้รับนำแบบไปเลือกอุปกรณ์ วัด แก้ พิมพ์ ผลิต และทดสอบของตัวเองได้ ยังไม่มีเครื่อง POS ที่ประกอบจริงซึ่งยืนยันว่าแบบเริ่มต้นใช้ได้กับอุปกรณ์ทุกรุ่น

## ที่มาของข้อมูล

| ข้อมูล | ที่มา | ใช้ต่ออย่างไร |
|---|---|---|
| จอ 165×105×6 mm, active 154×86 mm | ขนาดสมมติสำหรับสาธิตการออกแบบ ไม่ผูกกับสินค้าจริง | แทนด้วยการวัดจอที่เลือก รวม PCB หลังจอและสาย |
| SBC, MCU, พัดลมในคลังอุปกรณ์ | แม่แบบขนาด รู และพื้นที่ชิ้นส่วนที่ตั้งขึ้นเพื่อจัดวาง ไม่มี pinout สินค้าจริง | วัดบอร์ดและรูจริง แล้วกรอก connector จาก datasheet ผ่าน manifest |
| PCB accessory: ขอบบอร์ด รู ความหนา ตำแหน่งและ net | ดึงจาก `hardware/sources/accessory.kicad_pcb` ด้วย `return_manifest.py`; `board.json` มี SHA-256 ของ source | แก้ใน KiCad แล้ว export manifest ใหม่ ความหนาคือค่าตั้งในแบบ ไม่ใช่การวัดบอร์ดผลิต |
| พื้นที่ครอบชิ้นส่วน PCB | properties `BBN_Width/Height/Depth` ของ footprint เป็นค่าที่ออกแบบเผื่อ | ตรวจ datasheet และวัดชิ้นส่วน ขาที่ตัดเหลือและแนวติดตั้งจริง |
| ชิ้นส่วนวงจรและขั้วต่อ J1/J2 | `hardware/BOM.csv` มีผู้ผลิต รุ่น และ datasheet; J1/J2 คือ Würth 691137710002 | ตรวจรุ่นที่ซื้อกับ footprint และหมายเลข pad ตาม schematic ก่อนประกอบ |
| ผนัง 2.4 mm, เผื่อ 0.3 mm, ฐาน 60°, ช่องพอร์ตและระยะสาย | ค่าตั้งต้นในการออกแบบ ไม่ใช่ผล calibration หรือการวัดหัวปลั๊กจริง | ปรับตามวัสดุ เครื่องพิมพ์ ทิศแรง และหัวปลั๊ก/สายของเครื่อง |
| STL และขนาดชิ้นงาน | คำนวณจากแบบ JSON ด้วย geometry เดียวกับ preview | เปิดตรวจใน slicer ทดสอบพิมพ์และประกอบก่อนทำซ้ำ |
| ราคา สูตร สต็อกและยอดขายในหน้า POS | ข้อมูลร้านตัวอย่างและรายการที่ผู้ใช้ลองทำในเบราว์เซอร์ | ใช้ศึกษาซอฟต์แวร์ ไม่ใช่ราคามาตรฐาน สูตรรับรอง หรือผลยอดขายร้านจริง |

`sourceHash` บอก revision ของ PCB ต้นทางเท่านั้น หากแก้ขนาด/รูของ module ในเว็บ ค่าที่แก้อาจไม่ตรงกับ PCB แม้ยังมี hash เดิม ใช้ `return_manifest.py --check` ตรวจ manifest กับ PCB และเก็บ JSON ที่แก้แยกไว้

## ใบบันทึกอุปกรณ์ของผู้สร้าง

คัดลอกตารางนี้ไว้กับ JSON ของงาน ใส่ค่าที่ตรวจได้จริง ห้ามใส่คำว่า “ผ่าน” หากยังไม่ได้ตรวจ ช่องที่ว่างหมายถึงยังไม่ทราบ

| รายการ | ผู้ผลิต/รุ่นที่ใช้ | ไฟล์หรือ datasheet อ้างอิง | ค่าที่วัดจริง / วันที่ |
|---|---|---|---|
| จอ: ขอบนอก active thickness และ PCB หลังจอ | | | |
| คอมพิวเตอร์: PCB รูยึดและชิ้นส่วนสูงสุด | | | |
| พัดลม: ขนาด รู แรงดัน กระแสเริ่มหมุน | | | |
| PCB accessory: revision และชิ้นส่วนที่ซื้อ | | | |
| หัวปลั๊ก: รุ่น ขั้ว ระยะเสียบและแนวสาย | | | |
| แหล่งจ่ายแต่ละอุปกรณ์: แรงดัน/กระแส | | | |
| งานพิมพ์: วัสดุ nozzle clearance และสกรู | | | |

## ลำดับนำไปใช้

1. เลือกและบันทึกรุ่นอุปกรณ์ วัดตามตารางก่อนแก้ตัวเลขบนเว็บ จอและคอมพิวเตอร์ใช้ไฟตามผู้ผลิต บอร์ดเสริมจ่ายเฉพาะพัดลม/LED
2. แก้ PCB ใน KiCad หากต้องเปลี่ยนวงจร/ขั้วต่อ ตรวจ ERC/DRC แล้วส่ง `board.json` กลับเข้าเว็บ ตรวจพื้นที่ชนและทิศสาย
3. บันทึก JSON แล้วส่งออก ZIP ซึ่งมี 4 STL และ `BUILD-NOTES.txt` แนบข้อจำกัดไปกับแบบ ตรวจหน่วย รูยึด support และแนวพิมพ์ใน slicer
4. พิมพ์ชิ้นทดสอบ วัด clearance ประกอบโดยยังไม่จ่ายไฟ ตรวจสกรู ขาอุปกรณ์ พอร์ตและแรงแตะจอ
5. ทดสอบวงจรตาม [HARDWARE.md](HARDWARE.md) บันทึกโหลด แรงดันเอาต์พุต อุณหภูมิและผลทดสอบก่อนใช้ต่อเนื่อง

ผลตรวจดิจิทัลที่ทำแล้วดู [TEST-REPORT.md](TEST-REPORT.md) การผ่าน software tests/ERC/DRC ไม่ยืนยันการประกอบหรือสมรรถนะไฟฟ้า ยังไม่มีผลพิมพ์จริง ผลผลิต PCB ผลทดสอบโหลด/ความร้อน หรือ G-code ที่ตรวจผ่าน slicer ของชุดนี้
