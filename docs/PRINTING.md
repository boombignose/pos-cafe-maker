# วัด พิมพ์ และประกอบต้นแบบ

1. วัด outer/active area/thickness จอและ PCB ด้วยเวอร์เนียร์ วัดตำแหน่งรูจากมุมซ้ายล่าง ระบุระยะสูงสุดของชิ้นส่วน/ปลั๊กและการงอสาย ไม่ใช้ค่าตัวอย่างแทนการวัดจริง
2. ปรับผนัง/clearance/มุมฐานในเว็บ ย้ายบอร์ดให้พ้นจอ เสายึดและกันชน ตรวจ assembled/exploded/transparent และคำเตือนทุกจุด
3. นำเข้า manifest ล่าสุดหลังแก้ KiCad; ตรวจ sourceHash ด้วย `return_manifest.py --check` ก่อนอ้างอิงว่าเคสตรงกับ PCB
4. ดาวน์โหลด STL แยกชิ้น เปิดใน slicer ที่ตั้งเครื่องจริง หน่วยmm ไม่ auto-scale ชิ้นงาน ตรวจรูยึด/ช่องพอร์ตและเลเยอร์ผนัง/เสายึด
5. เริ่มด้วย coupon ทดสอบรู/ระยะเผื่อและส่วนยึดขนาดเล็ก ก่อนพิมพ์ชุดเต็ม PLA เหมาะกับการลองฟิต; เลือกวัสดุตามอุณหภูมิจริงของอุปกรณ์ภายหลัง ไม่มีผลวัดความร้อนในชุดนี้
6. สกรู/น็อต M3 ใช้ความยาวตาม stack จริง; บอร์ดสกรูM2.5/M3ต้องเลือกตามรูที่วัด อย่าขันเกินจนกดแผงจอหรือแตะทองแดง ใช้ spacer/washer เมื่อจำเป็น
7. รักษา airflow/ระยะปลั๊ก จัดสายไม่ให้หนีบตอนปิดฝา ติดยางกันลื่นและทดสอบแรงแตะจอ/ความมั่นคงของแท่น; รูฐานสำหรับยึดโต๊ะเป็นทางเลือก
8. ตรวจไฟDC/ขั้ว/แรงดันตาม HARDWARE.md ก่อนเสียบจอและคอมพิวเตอร์ แหล่งจ่ายของแต่ละโมดูลแยกตามผู้ผลิต บอร์ดเสริมเป็นต้นแบบ fan/LEDเท่านั้น

Slicer output เป็นการตรวจว่า softwareสร้างเลเยอร์ได้ ไม่ใช่ G-code ที่รับรองสำหรับเครื่องของคุณ ไม่แจก G-codeเป็นค่าเริ่มต้น ต้องใช้ profile/calibration ของเครื่องจริง พิมพ์/ประกอบ/วัดอุณหภูมิเองก่อนใช้งานกับลูกค้า

## ประกอบแท่นรองด้านหลัง รุ่น0.1.2

- กรอบ/กล่อง/ฝายึดกันด้วยรูมุม4จุด กรอบหน้ามีหลุมหัวสกรูทรงกรวยตื้นสำหรับหัวจม ตรวจหัวสกรูและผนังที่เหลือจริงก่อนขัน ไม่รับรองว่าหัวสินค้าทุกรุ่นจะเสมอผิว
- ฝามีตัวประคองหลังขอบจอ4จุด ระยะปลายถึง envelope หลังจอเท่ากับ clearance ที่ตั้งไว้ ตรวจว่าเป็นส่วนรับแรงได้ของโมดูลจริง ใช้วัสดุรองที่วัดแล้วให้พอดี ห้ามบีบกระจก flex cable หรือ PCB ห้ามขันเพื่อฝืนจอที่หนากว่าแบบ
- จับน็อตM3ในช่องหกเหลี่ยมด้านในฝา4จุดก่อนปิดฝา ค่าเริ่มต้นช่องมีความกว้างระหว่างหน้าแบนประมาณ5.72mm ลึก2.6mm สำหรับทดสอบ fit ของน็อตจริง ค่าจะเปลี่ยนตามผนัง
- แผ่นยึดบนแท่นตรงกับรูฝา ลายรูค่าเริ่มต้น80×50mm ใช้สกรูM3พร้อมแหวนรอง4ชุด ขันจากด้านแท่นเข้าฝา เลือกความยาวจาก stack ที่พิมพ์จริง ปลายต้องไม่ล้ำพ้นฐานรองน็อตด้านในหรือชนบอร์ด ค่าเริ่มต้นฐานรองเริ่มที่Z45.2mm ตามระบบพิกัดเคส; หากแก้ผนัง/ความลึกต้องวัดใหม่
- ใช้ช่องคู่3×6mmบนฝาร้อย cable tie และทางลอดที่แท่นเพื่อนำสายออกหลังเครื่อง วัดความกว้างหัวปลั๊กและรัศมีงอสายเอง ทางลอดไม่รับรองว่าสอดหัวปลั๊กทุกรุ่นผ่านได้ และไม่มีการกำหนดรุ่นสายให้
- ฐานเป็นแท่นมุมคงที่ เปลี่ยนค่ามุมแล้วต้องพิมพ์ใหม่ แผ่นยึดเอียงและทางลอดสายมีส่วนยื่น ต้องตรวจ support/bridge และการถอด support ใน slicer ก่อนพิมพ์ รูโต๊ะ4จุดไม่ได้พิสูจน์ความมั่นคงหากไม่ยึดโต๊ะ
- ฝา export ให้ผิวกว้างอยู่บนเตียง ตัวประคองหลังจอและเสา PCB จะพิมพ์ขึ้นด้านบน แบบยังไม่ผ่านการพิมพ์ ประกอบ ทดสอบแรงแตะหรือระยะสกรูจริง
