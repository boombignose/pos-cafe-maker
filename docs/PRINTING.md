# วัด พิมพ์ และประกอบต้นแบบ

1. วัด outer/active area/thickness จอและ PCB ด้วยเวอร์เนียร์ วัดตำแหน่งรูจากมุมซ้ายล่าง ระบุระยะสูงสุดของชิ้นส่วน/ปลั๊กและการงอสาย ไม่ใช้ค่าตัวอย่างแทนการวัดจริง
2. ปรับผนัง/clearance/มุมฐานในเว็บ ย้ายบอร์ดให้พ้นจอ เสายึดและกันชน ตรวจ assembled/exploded/transparent และคำเตือนทุกจุด
3. นำเข้า manifest ล่าสุดหลังแก้ KiCad; ตรวจ sourceHash ด้วย `return_manifest.py --check` ก่อนอ้างอิงว่าเคสตรงกับ PCB
4. ดาวน์โหลด STL แยกชิ้น เปิดใน slicer ที่ตั้งเครื่องจริง หน่วยmm ไม่ auto-scale ชิ้นงาน ตรวจรูยึด/ช่องพอร์ตและเลเยอร์ผนัง/เสายึด
5. เริ่มด้วย coupon ทดสอบรู/ระยะเผื่อและส่วนยึดขนาดเล็ก ก่อนพิมพ์ชุดเต็ม PLA เหมาะกับการลองฟิต; เลือกวัสดุตามอุณหภูมิจริงของอุปกรณ์ภายหลัง ไม่มีผลวัดความร้อนในชุดนี้
6. สกรู/น็อต M3 ใช้ความยาวตาม stack จริง; บอร์ดสกรูM2.5/M3ต้องเลือกตามรูที่วัด อย่าขันเกินจนกดแผงจอหรือแตะทองแดง ใช้ spacer/washer เมื่อจำเป็น
7. รักษา airflow/ระยะปลั๊ก จัดสายไม่ให้หนีบตอนปิดฝา ติดยางกันลื่นและทดสอบแรงแตะจอ/ความมั่นคงของ cradle; รูฐานสำหรับยึดโต๊ะเป็นทางเลือก
8. ตรวจไฟDC/ขั้ว/แรงดันตาม HARDWARE.md ก่อนเสียบจอและคอมพิวเตอร์ แหล่งจ่ายของแต่ละโมดูลแยกตามผู้ผลิต บอร์ดเสริมเป็นต้นแบบ fan/LEDเท่านั้น

Slicer output เป็นการตรวจว่า softwareสร้างเลเยอร์ได้ ไม่ใช่ G-code ที่รับรองสำหรับเครื่องของคุณ ไม่แจก G-codeเป็นค่าเริ่มต้น ต้องใช้ profile/calibration ของเครื่องจริง พิมพ์/ประกอบ/วัดอุณหภูมิเองก่อนใช้งานกับลูกค้า
